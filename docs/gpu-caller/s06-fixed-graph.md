# Fixed SUP GPU graph

`internal/model/sup_gpu*.go` implements one fixed SUP v5.2 graph in Go for N32/chunk768/T64 and N32/chunk12288/T1024. Both have C512/H8/D64, 18 layers, E4096, I8 and FP8 enabled, remove_bits4 and default SwiGLU. Half NTC scores have shape `[32,128,4096]` and `[32,2048,4096]` respectively. The production CLI remains CPU only.

The source is Dorado `8b8fc5d36a9c0baab262a743cb175b5878e38ca6`. `basecall/model/TxModel.cpp:27-37` selects `ConvStack::forward` when `aux == nullptr`. Each of the five convolutions uses ATen Conv1d followed by in-place SiLU. `ConvStack.cpp:169-186` returns a transposed NTC view. This fixed route does not select the WorkingMemory window/GEMM, CUTLASS last-convolution or VCS paths. Those paths are not substitutes for the retained fixed oracle.

Go binds all 139 archive roles through the authoritative SUP manifest and the existing native CPU archive reader. Go converts F32 parameters to half, interleaves Q/K, quantizes the unrounded QKV half rows, packs the I8/FP8 and fallback half caches, then applies the source half remove_bits operation. The FP8 FC1 shuffle is also applied to the retained FC1 half cache. FP8 and I8 data are unchanged by half rounding. CRF weights are half-cast before their source scale5 multiplication.

Go generates all 4096 RoPE position/frequency rows. The theta power is cast to half before reciprocal. The reciprocal, arange and frequency product are each rounded to half. Individual Torch CUDA half sin and cos operations supply the transcendental math. Go chooses the interleave and `[256,8,16,8]` tile through checked storage views and copies. No native oracle table or later graph value supplies production data.

The encoder has seven ordered Koi calls per layer. They are QKV rotary, masked attention with window127/128, projection, residual RMS norm with FP8 output, SwiGLU, FC2 and residual RMS norm with I8 output. Go owns the descriptors, scale storage, cache lifetime, counter zeros, alpha, calls and order. Norms intentionally write the half residual in place. Other writable operands must have disjoint complete byte intervals. Cancellation or any operation/observer/cleanup failure returns no result.

One grouped ABI symbol, `nt_cuda_sup_primitive`, exposes a closed operation enum. It does not expose an encoder or model class. The native implementation independently repeats dtype, geometry, tags, explicit scale owner, stream/device ownership and byte-alias checks. It uses the existing `CUDAWork` owner retention and drain/recovery mechanism. The boundary also supplies individual strided copy, row quantization, Conv1d/SiLU, sin/cos and linear math. Upsampling retains the source's half matmul followed by a separate half bias addition and reshape. The final CRF uses matmul without bias.

`ForwardObserved` returns independent host byte snapshots. Before-removal cache events describe Go host preparation; after-removal cache events download the actual uploaded owners and check their role, metadata and scale binding. A changed uploaded byte therefore reaches the comparator independently of later graph outputs. Observers receive no live storage handles. The verification consumer compares every retained logical payload and its full backing, all descriptors, exact event order and final original-source score digest. The accepted tiny fixed oracle has 191 events and 733 tensors, each with zero offset and identical logical/backing digests. The consumer reads no native intermediate into the graph.

`verification/supgpu/graph.Consume` returns `ErrRuntimeHeld` before opening any path or native library. It has no arming option. A separate reviewed integration must connect the accepted current backend, current closed CGO1 build, CPU13 qualification and shared audited runtime guard. The private numerical comparison body is present for that integration. This change does not qualify a native compilation, GPU computation, full caller, biological result or performance claim.

The focused host tests cover fixed descriptors, complete tile indexing, packing/rounding order, immutable snapshots, nonfinite values, overflow, byte aliases, cancellation and first-failure stop behavior. CGO1 fake tests exercise the actual C loader and wire marshalling with host-memory C libraries. Fake checks do not establish numerical parity or the current native compiler/runtime qualification.

The source-default fixed geometry is available through `FullFixedSUPGPUProfile`. It selects N32, chunk12288, encoder T1024 and scores `[32,2048,4096]`. `FixedSUPGPUProfile` retains the tiny N32, chunk768 and T64 oracle geometry. Both select the same production graph and require the same flags. Neither profile selects VCS.

`tensor.SUPGeometry` admits only these two complete geometries. The checked enum drives convolution times, NCT transpose strides, quantization rows, T/16 tiles, N*T/16 flattened matrix rows, all encoder intermediates, untile strides, upsample and scores. It crosses the `nt_cuda_sup_primitive` ABI as an explicit uint32 argument. Go and native code reject unknown geometry and reject operands from the other profile. Tags, scales, writable byte intervals and ownership keep their existing checks. The full 4096-position RoPE cache and all parameter shapes remain fixed. QKV receives only the selected T-position view of that complete cache.

This changes the unintegrated SUP symbol's call signature. The backend and loader must be rebuilt from the same source closure. A retained library built with the prior SUP signature cannot be reused. The tiny capture importer and held numerical consumer retain their existing contract and do not admit a full capture.

The full geometry has source and host metadata coverage only. No full native oracle capture, C++ backend compilation, real graph execution, numerical equality, memory qualification, decoder/caller integration, biological result or performance is established by this unit. The native dispatch still performs one mathematical operation per call. Fixed aux=nullptr remains distinct from source VCS, whose auxiliary tables, effective batch granularity and kernel paths require a separate port.
